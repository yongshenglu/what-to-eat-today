# 🍽️ 今天吃什么

> 每天想"今天烧什么"太费神？把你会做的菜录进去，点一下就帮你配好一餐。

一个纯静态的小网页，手机上「添加到主屏幕」就能当 App 用。**不用注册、不用装东西、不联网也能用**，菜谱只存在你自己的手机里。

---

## ✨ 能做什么

- **一餐组合**：一键生成「1荤 + 1素 + 1汤」之类的搭配，不用自己纠结
- **不满意就换**：整餐重摇，或者只把某一道换掉
- **避开重复**：最近 7 天做过的菜不再出现，轮完一圈才重新开始
- **菜谱管理**：随时加菜、改名、改分类、删除，自动保存
- **吃过记录**：打个卡，看看最近都吃了啥
- **一键备份**：导出 / 导入 JSON，换手机不丢数据

## 📱 打开方式

**方法一（推荐）：添加到主屏幕，当 App 用**

打开网址后——

| iPhone (Safari) | 安卓 (Chrome) |
|---|---|
| 底部「分享」按钮 → 「添加到主屏幕」 | 右上角「⋮」→ 「添加到主屏幕」 |

桌面上会出现一个冒热气的饭碗图标，点开就是全屏 App，连地址栏都没有。

**方法二：直接用浏览器打开网址**，功能一样，只是没有独立图标。

## 🥘 怎么用

1. 切到「**🥘 我的菜谱**」，把你会做的菜一道道加进去
   - 想先试试？点「**📗 载入示例菜谱**」，会填入 38 道家常菜，再慢慢改成你自己的
2. 回到「**🎲 今天吃什么**」，点「**🎲 重新随机**」
3. 觉得哪道不合心意，点它旁边的「**🔄 换一个**」
4. 定下来了就点「**✅ 就吃这些**」——这道菜 7 天内不会再出现

### 随机设置

展开「**⚙️ 随机设置**」可以调：

- **餐量**：简单（1荤1素）／标准（1荤1素1汤）／丰盛（2荤2素1汤1主食）
- **每类几道**：想更精细就自己加减
- **避开最近吃过的**：默认 7 天，0 = 不避开（纯随机）

## 💾 数据在哪

**默认全部存在你手机/电脑的浏览器本地**（localStorage），不上传任何服务器。

| 数据 | 存在哪 | 会不会同步到 GitHub |
|---|---|---|
| 🥘 菜谱 | 浏览器本地 | ✅ 开启同步后会 |
| 📅 吃过记录 | 浏览器本地 | ❌ 永不上传 |
| ⚙️ 随机设置 | 浏览器本地 | ❌ 永不上传 |
| 🔑 同步 Token | 浏览器本地 | ❌ 永不上传、不进备份文件 |

⚠️ 如果没开同步：

- **清浏览器缓存 / 换设备会丢数据**，请定期点「**⬇️ 导出备份**」存一份
- 换了手机，把备份文件传过去，点「**⬆️ 导入备份**」即可（可选**合并**或**覆盖**）

## ☁️ 开启 GitHub 同步（可选，推荐）

开启后菜谱会自动存进你的 GitHub 仓库，换手机、清缓存都不怕。**吃过记录和设置不会上传。**

### 只需做一次

1. 打开 [创建 Token 页面](https://github.com/settings/personal-access-tokens/new)（需先登录 GitHub）
2. 名字随便填（比如 `今天吃什么`），有效期选 `No expiration` 或 `1 year`
3. **Repository access** 选 **Only select repositories**，然后**只勾** `meal-data` 这一个仓库
4. 展开 **Permissions → Repository permissions**，把 **Contents** 改成 **Read and write**，**其余全部不要动**
5. 点 **Generate token**，复制那串 `github_pat_` 开头的字符
6. 回到 App →「🥘 我的菜谱」→ 拉到最下面「☁️ GitHub 同步」→ 粘进去 → 点「**测试连接**」

看到 ✅ 就成了。之后加菜、改菜、删菜会自动同步，顶上能看到同步状态。

### 同步怎么工作的

- **打开 App 时**自动拉一次，把其他设备的改动并进来
- **改动后 5 秒**自动推送到仓库（防止每敲一下就产生一个提交）
- **两台设备同时用**也不会互相抹掉：两边新增的都保留，删除的会传播（不会「删了又复活」），同名同分类自动收敛成一道
- **网络不好**时照常能用本地数据，联网后自动补传

### 换手机怎么办

1. 新手机上打开网址
2. 重新生成一个 Token 粘进去（旧 Token 不会跟过来）
3. 点「立即同步」，菜谱全部回来

### 安全说明

- Token **只存在你这台设备的浏览器里**，不进代码仓库，也**不会写进导出的备份文件**
- 签发时只勾了 `meal-data` 一个仓库、只给了 Contents 读写，**即使泄露也动不了你的其他仓库**
- 随时可在 [GitHub Token 页面](https://github.com/settings/personal-access-tokens) 撤销
- ⚠️ 能用你解锁手机的人能看到 Token，介意的话可以在用完后点「清除 Token」

> **不要**用电脑上 `gh` 命令行那个 Token —— 它有整个账号的 `repo` 权限，泄露等于全号失守。

| 文件 | 作用 |
|---|---|
| `index.html` | 主应用，全部逻辑和样式都在里面 |

## 🧩 技术说明

原生 HTML + CSS + JavaScript，**单文件、无框架、无构建步骤**。数据存在 `localStorage` 的三个键下：

| 键 | 内容 |
|---|---|
| `jctsm_dishes` | 菜谱 `[{id, name, category}]` |
| `jctsm_history` | 吃过记录 `[{time, dishes[]}]` |
| `jctsm_config` | 设置 `{combo, avoidDays}` |

菜谱分类固定 5 种：**荤菜 / 素菜 / 汤 / 主食 / 凉菜**。
