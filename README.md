# 🍽️ 今天吃什么

> 每天想"今天烧什么"太费神？把你会做的菜录进去，点一下就帮你配好一餐。

一个纯静态的小网页，手机上「添加到主屏幕」就能当 App 用。**不用注册、不用装东西、不联网也能用**，菜谱只存在你自己的手机里。

---

## ✨ 能做什么

- **一餐组合**：一键生成「1荤 + 1素 + 1汤」之类的搭配，不用自己纠结
- **不满意就换**：整餐重摇，或者只把某一道换掉
- **避开重复**：最近 7 天做过的菜不再出现，轮完一圈才重新开始
- **菜谱管理**：随时加菜、改名、改分类、删除，自动保存
- **吃过记录**：打个卡，看看最近都吃了啥
- **一键备份**：导出 / 导入 JSON，换手机不丢数据

## 📱 打开方式

**方法一（推荐）：添加到主屏幕，当 App 用**

打开网址后——

| iPhone (Safari) | 安卓 (Chrome) |
|---|---|
| 底部「分享」按钮 → 「添加到主屏幕」 | 右上角「⋮」→ 「添加到主屏幕」 |

桌面上会出现一个冒热气的饭碗图标，点开就是全屏 App，连地址栏都没有。

**方法二：直接用浏览器打开网址**，功能一样，只是没有独立图标。

## 🥘 怎么用

1. 切到「**🥘 我的菜谱**」，把你会做的菜一道道加进去
   - 想先试试？点「**📗 载入示例菜谱**」，会填入 38 道家常菜，再慢慢改成你自己的
2. 回到「**🎲 今天吃什么**」，点「**🎲 重新随机**」
3. 觉得哪道不合心意，点它旁边的「**🔄 换一个**」
4. 定下来了就点「**✅ 就吃这些**」——这道菜 7 天内不会再出现

### 随机设置

展开「**⚙️ 随机设置**」可以调：

- **餐量**：简单（1荤1素）／标准（1荤1素1汤）／丰盛（2荤2素1汤1主食）
- **每类几道**：想更精细就自己加减
- **避开最近吃过的**：默认 7 天，0 = 不避开（纯随机）

## 💾 数据在哪

**全部存在你手机/电脑的浏览器本地**（localStorage），不会上传到任何服务器，也不会进入这个 GitHub 仓库。

⚠️ 因此要注意：

- **清浏览器缓存 / 换设备会丢数据**，请定期在「🥘 我的菜谱」里点「**⬇️ 导出备份**」存一份
- 换了手机，把备份文件传过去，点「**⬆️ 导入备份**」即可
- 导入时可选**合并**（保留现有的）或**覆盖**（清空后导入）

## 📁 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 主应用，全部逻辑和样式都在里面 |
| `manifest.json` | PWA 配置（添加到主屏幕用） |
| `icon-192.png` / `icon-512.png` | 应用图标 |
| `dishes.sample.json` | 示例菜谱数据，可以直接改了导入 |
| `make_icons.py` | 生成图标的脚本（想换图标时用） |

本地想先看看效果，可以直接双击 `index.html` 用浏览器打开。

## 🧩 技术说明

原生 HTML + CSS + JavaScript，**单文件、无框架、无构建步骤**。数据存在 `localStorage` 的三个键下：

| 键 | 内容 |
|---|---|
| `jctsm_dishes` | 菜谱 `[{id, name, category}]` |
| `jctsm_history` | 吃过记录 `[{time, dishes[]}]` |
| `jctsm_config` | 设置 `{combo, avoidDays}` |

菜谱分类固定 5 种：**荤菜 / 素菜 / 汤 / 主食 / 凉菜**。
