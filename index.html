☁️ GitHub 同步 ☁️ 未开启
还没有开启同步。填好下面两项，菜谱就会自动存到你的 GitHub 仓库，换手机不丢。
怎么开起来（只需做一次）
  1. 打开 ，需要先登录
  2. 名字随便填（比如 今天吃什么），有效期选 No expiration 或 1 year
  3. Repository access 选 Only select repositories，然后只勾 meal-data 这一个
  4. 展开 Permissions → Repository permissions，把 Contents 改成 Read and write。其余全部不要动
  5. 点 Generate token，把那串 github_pat_ 开头的字符复制，粘到上面
  6. 点「测试连接」，看到 ✅ 就成了
安全说明：Token 只存在这台设备的浏览器里，不进代码仓库，也不会写进「导出备份」的文件。 随时可在 撤销。 填的时候只勾 meal-data 一个仓库，万一泄露也动不了你的其他仓库。
只同步菜谱。吃过记录和随机设置只留在这台设备上，不会上传。
